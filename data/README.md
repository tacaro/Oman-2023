# Data

Raw data reported in the study.

## Directory
- 16S: 16S data
- 16S_batch2: second batch of 16S data
- Caro DIC Run1 March 6: DIC/d13C-DIC data
- cline_assays: sulfide concentration data
- gc_data: gas chromatography data
- Kelemen 2020: Kelemen 2020 supplementary data on rock porosity/density
- nanoSIMS_tables: collated tables of nanoSIMS single-cell data
- Picarro: CRDS data
- Templeton 2021: Templeton et al. (2021, JGR Biogeosci) data of rock-hosted cell abundances
