# Sourced functions

- analyze_picarro.R: a script for analyzing CRDS data from Picarro instrument
- calculate_mu.R: a function for calculating growth rate of single-cells
- calculate_sigma_mu.R: a function for propagating error in growth rate calculations
- color palettes.R: color palettes for plotting
- kg_ha_to_tonne_km2.R: a function for unit conversion kg per hectare to tonnes per km2
- theme_om23.R: a custom ggplot2 theme
